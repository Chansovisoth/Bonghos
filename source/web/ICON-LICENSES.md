# Vendored Icon Assets

## Solar

- Creator: 480 Design
- Source: https://icon-sets.iconify.design/solar/
- Distribution: Iconify
- License: CC BY 4.0
- License text: https://creativecommons.org/licenses/by/4.0/
- Retrieved: 2026-08-03

Bonghos vendors an unchanged subset of 38 Solar linear icons in `src/solar-icons.json`. The icons are used in navigation and familiar command buttons. No Iconify runtime or external icon request is required.

## Provider Icons

- Minecraft Fabric icon: Material Icon Theme, MIT License
- Distribution: Iconify
- Source: https://icon-sets.iconify.design/material-icon-theme/minecraft-fabric/
- Retrieved: 2026-08-04

Provider icons are embedded locally in `src/app.js` as a fallback. Unknown providers fall back to the existing Solar server icon.

The displayed provider marks use locally vendored copies of their official favicons:

- https://static-beta.curseforge.com/images/favicon.ico
